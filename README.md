# Police-Use-of-Force-Analysis
## Overview
This project analyzes fatal police shootings in the United States and explores how incident counts relate to socioeconomic indicators such as poverty rates, income, education levels, and demographics.

The goal is to identify geographic patterns, demographic disparities, and time trends using public datasets.

---

## Data Sources

- Washington Post Fatal Police Shootings Database
- U.S. Census Data (Income, Poverty, Education, Race by City/State)

---

## Key Questions

- Which states and cities have the highest incident counts?
- How do poverty and education levels relate to incident counts?
- What demographic patterns appear in the data?
- How have police killings changed over time (2015–present)?

---

## Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Plotly

---

## Methodology

- Cleaned and standardized multiple public datasets
- Handled missing values and duplicate records
- Aggregated data at state and city levels
- Merged Census socioeconomic indicators with fatality data
- Conducted regression analysis to explore poverty vs education relationships
- Built choropleth maps to visualize geographic concentration
- Performed time-series analysis of annual incident counts

---

## Key Findings

- Fatal police shootings are geographically concentrated in a small number of states and major metropolitan areas.
- Higher poverty rates and lower high school graduation rates are associated with higher incident counts at the state level.
- Demographic patterns vary across regions.
- Most victims were male.
- Annual incidents remain persistently high from 2015 onward.

---

## Limitations

- Analysis primarily uses incident counts (not population-adjusted rates).
- Public data reporting may vary across states.
- Socioeconomic indicators are aggregated and may mask within-state variation.

## How to Run

Install dependencies listed in requirements.txt and run the Jupyter notebook.
